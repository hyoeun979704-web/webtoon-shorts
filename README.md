# 웹툰 숏폼 자동 생성기

**Google Sheets**에서 설정과 작업을 관리하고, 각 서비스의 Pro 구독을 브라우저 자동화로 조작하여
25~40초 웹툰 스타일 숏폼 영상을 자동 생성합니다.

## 파이프라인

```
[Google Sheets] 작업목록 → [Claude 웹] 대본 → [시트에서 대본 확인/수정] → [ChatGPT] 이미지 → [Typecast] 음성 → [CapCut] 영상
          ↑ 설정                                                                    ↓ 실시간 진행상황 업데이트
```

## Google Sheets 구조

### [설정] 탭
| 항목 | 값 | 설명 |
|------|------|------|
| 성우 이름 | 차은우 | Typecast 성우 |
| 이미지 스타일 | webtoon style, manhwa art... | DALL-E 프롬프트에 추가 |
| 장면 수 | 5 | 장면 개수 |
| 목표 길이(초) | 30 | 영상 목표 길이 |
| 편집 모드 | capcut | capcut / skip |
| 자동 대본 승인 | N | Y면 대본 수정 없이 바로 진행 |

### [작업목록] 탭
| 번호 | 주제 | 상태 | 제목 | 장면수 | 시작시간 | 완료시간 | 출력경로 | 비고 |
|------|------|------|------|--------|----------|----------|----------|------|
| 1 | 직장인의 월요일 아침 | 대기 | | | | | | |
| 2 | 고양이의 하루 | 대기 | | | | | | |

→ **'대기'** 상태인 작업이 순서대로 처리됩니다.
→ 진행중에는 상태가 실시간 업데이트: `1/4 대본 생성중` → `2/4 이미지 생성중` → ...

### [대본] 탭
| 장면번호 | 나레이션 | 이미지 프롬프트 | 자막 | 이미지 상태 | 음성 상태 |
|----------|----------|-----------------|------|-------------|-----------|

→ 대본 생성 후 자동으로 채워집니다. **수정 후 Enter로 진행.**

## 설치

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. Playwright 브라우저 설치
playwright install chromium

# 3. Google OAuth 설정
#    - Google Cloud Console에서 OAuth 2.0 클라이언트 ID 생성
#    - 데스크톱 앱 유형 선택
#    - credentials.json 다운로드 → 프로젝트 루트에 배치
#    - 최초 실행시 브라우저에서 Google 로그인

# 4. 환경변수 설정 (선택)
cp .env.example .env
```

## 사용법

```bash
# 1) 시트 초기 세팅 (탭, 헤더 자동 생성)
python main.py --init

# 2) 시트에서 설정 입력 + 작업목록에 주제 추가 + 상태를 '대기'로 설정

# 3) 각 서비스 최초 로그인
python main.py --login

# 4) 실행! (시트의 '대기' 작업을 순서대로 처리)
python main.py
```

## 워크플로우

1. **[작업목록]에 주제 입력** → 상태를 `대기`로 설정
2. `python main.py` 실행
3. Claude가 대본 생성 → **[대본] 탭에 기록**
4. 시트에서 나레이션/프롬프트 확인 및 수정 → **Enter로 계속**
5. ChatGPT에서 이미지 생성 (장면별 실시간 상태 업데이트)
6. Typecast에서 음성 합성 (장면별 실시간 상태 업데이트)
7. CapCut에서 영상 편집 및 내보내기
8. **[작업목록]에 '완료' + 출력경로 기록**
